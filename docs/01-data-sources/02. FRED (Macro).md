# 02. FRED (Macro)

## Status

Draft — awaiting review. Defines the macro data source (FRED) and the exact
series the pipeline pulls. Consumed by the Macro & Currency analysis module.

## Role

[FRED](https://fred.stlouisfed.org/) (Federal Reserve Economic Data, St. Louis
Fed) is the authoritative, free source for US macro series. It is the gold
standard for a macro-aware strategy and is essential to the owner's
"semiconductor war + FOMC" thesis.

- **Auth:** free API key, stored as GitHub Secret `FRED_API_KEY`.
- **Limit (free):** ~1,000 requests/day — far above weekly needs.
- **Endpoint:** `https://api.stlouisfed.org/fred/series/observations`.
- **Resilience:** a failed series yields a flagged, partial result with a note;
  the run never crashes on a missing series (fail-safe).

## Series pulled

| Series ID | Meaning | Why it matters to this portfolio |
|-----------|---------|----------------------------------|
| `DGS10` | 10-Year Treasury yield | Rising yields pressure growth/semis; a key driver of this period's rotation out of risk. |
| `DGS2` | 2-Year Treasury yield | Short-end / rate-expectations read. |
| `T10Y2Y` | 10Y−2Y spread (yield curve) | Classic recession signal; un-inversion / steepening context. |
| `DFF` | Federal Funds Effective Rate | Fed policy stance (the "FOMC" axis of the thesis). |
| `DTWEXBGS` | Broad US Dollar Index | Dollar strength backdrop; interacts with the USD/IDR cost of entry. |
| `VIXCLS` | CBOE VIX | Market fear gauge; contextualizes "risk-off" weeks. |

> Series IDs verified against FRED. Values are public-domain data from the
> Federal Reserve Bank of St. Louis.

## Currency note (USD/IDR)

USD/IDR is **not** a FRED series in the form this project needs weekly; it is
sourced from the price source (Yahoo `IDR=X`, already proven in the predecessor)
and from the ledger's per-transaction rate. FRED's `DTWEXBGS` provides the
broad-dollar *backdrop* only. The Macro & Currency analysis module combines
both.

## Output shape

For each series: latest value, the value ~1 week and ~1 month ago, and the
change. The analysis module turns these into a macro read; this data source only
fetches and normalizes.

## Test cases

Deterministic tests use recorded fixture responses (no live network).

1. **TC-01 Parse latest observation.** Given a fixture with observations ending
   in a known value, the latest value and date are extracted correctly.
2. **TC-02 Missing/`.` observation handled.** FRED uses `"."` for missing days;
   these are skipped, and the latest *valid* value is used.
3. **TC-03 Week/month deltas.** Given a fixture series, 1-week and 1-month
   changes equal the hand-computed deltas.
4. **TC-04 Failed series is flagged, not fatal.** One series returns an error →
   it is marked unavailable with a note; the other series still return values.
5. **TC-05 API key never logged.** The request builder includes the key as a
   query param but it is redacted from any logged URL/error.
