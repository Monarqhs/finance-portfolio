# 03. Opportunity Scanner (Sector ETFs)

## Status

Draft — awaiting review. Third analysis module. Scans a watchlist of sector /
thematic ETFs and surfaces diversification candidates. Deterministic and
auditable; it ranks *current conditions*, it does not predict returns.

## Why this module

The owner asked to be shown sector ETFs worth considering. This module directly
addresses the portfolio's ~100% semiconductor concentration by looking for ETFs
that are (a) in a healthy trend and (b) **low-correlated to the owner's
semiconductor exposure** — i.e. positions that would actually reduce risk, not
just add more of the same.

## ETF universe (default watchlist)

Prices from the proven price source (Yahoo). No new paid data. All are liquid,
free to track, and chosen to span low-correlation diversifiers relevant to the
current regime.

| ETF | Sector / theme | Diversification rationale |
|-----|----------------|---------------------------|
| `XLV` | Health Care | Defensive, low correlation to semis; classic ballast during AI-bubble jitters. |
| `XLE` | Energy | Inflation / geopolitical hedge (oil rises during conflict). |
| `XLF` | Financials | Benefits when yields rise — the exact driver of the current rotation. |
| `XLU` | Utilities | Defensive **and** an "AI power demand" proxy (data-center electricity). |
| `XLP` | Consumer Staples | Risk-off harbor. |
| `GLD` | Gold | Geopolitical hedge; the owner already holds a gold thesis (`GC=F`). |
| `XLK` | Broad Tech | Reference/benchmark for the current tilt (not a diversifier). |

The watchlist is config-driven; the owner can add/remove tickers. `XLK` and the
semi exposure act as the "correlation reference" to measure diversification
against.

## Inputs

- ~1y daily closes per ETF (price source).
- The portfolio's current semiconductor/return series (from Risk module) as the
  **correlation reference**.
- Macro regime tags (from Macro module) — used only to annotate *why* a
  candidate fits the current backdrop, never to predict.

## Scoring

A transparent, additive score per ETF. Every component is a measured number;
the total and its parts are shown so the ranking is auditable.

| Component | Measure | Points (default) |
|-----------|---------|------------------|
| **Trend** | price vs SMA50 & SMA200 | +2 above both, +1 above SMA200 only, 0/−1 below SMA200 |
| **Momentum** | RSI-14 | +1 if 40–65 (healthy), 0 if 30–40 or 65–70, −1 if >70 (overbought) or <30 (falling knife) |
| **Diversification** | correlation to semi reference (1y) | +2 if corr < 0.3, +1 if 0.3–0.5, 0 if 0.5–0.7, −1 if > 0.7 |
| **Discount** | drawdown from 52w high | +1 if −10%…−20% in an intact uptrend (buy-the-dip), 0 otherwise |
| **Regime fit** | matches an active macro tag | +1 if the ETF's rationale matches a current tag (e.g. `XLF` + `YIELDS_RISING`) |

Candidates are ranked by total score. The report shows the **top 2–3** with
their full score breakdown and an evidence-first one-liner, plus the explicit
limitation that this is a current-condition ranking, not a return forecast and
not a recommendation to buy.

## Output

A `Opportunities` result: ranked list, each with ticker, total score, per-
component breakdown, correlation-to-semi, trend/RSI values, and a short
rationale referencing the active macro tags. Reuses the technical primitives
(SMA/RSI/drawdown) from the Signal Engine so logic is not duplicated.

## Guardrails

- **Never says "buy".** Phrasing is "candidate to consider for reducing
  concentration," always paired with the measured evidence and the limitation.
- No prediction of future price or return.
- An ETF with insufficient history is excluded from scoring with a note, not
  guessed.

## Test cases

Deterministic tests over fixed price series.

1. **TC-01 Trend scoring.** Price above both SMAs → trend +2; above SMA200 only
   → +1; below SMA200 → 0 or −1 per rule.
2. **TC-02 Momentum scoring.** RSI 50 → +1; RSI 68 → 0; RSI 75 → −1; RSI 25 →
   −1.
3. **TC-03 Diversification scoring.** Reference series and a candidate with
   correlation 0.1 → +2; correlation 0.8 → −1.
4. **TC-04 Discount scoring.** Intact uptrend, −15% from 52w high → +1; −3% → 0.
5. **TC-05 Regime fit.** `XLF` scored while `YIELDS_RISING` is active → +1;
   same ETF with no matching active tag → 0.
6. **TC-06 Ranking order.** Given three ETFs with known component scores, the
   output is sorted by total descending.
7. **TC-07 Breakdown present.** Each ranked entry includes every component's
   points and the raw measures (corr, RSI, trend), enforcing auditability.
8. **TC-08 Insufficient history excluded.** An ETF with < SMA200 history is
   excluded with a note, not scored on partial data.
9. **TC-09 No buy language.** Generated rationale text contains no imperative
   buy phrasing (asserted against a banned-phrase list) and always includes a
   limitation clause.
