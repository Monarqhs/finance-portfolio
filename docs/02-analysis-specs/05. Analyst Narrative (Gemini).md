# 05. Analyst Narrative (Gemini)

## Status

Draft — awaiting review. Optional narrative layer. It sits **on top of** the
deterministic modules and turns their outputs into a readable analyst note. It
is strictly bounded: it reasons only from supplied evidence, never predicts
prices, and never receives the owner's real amounts or PII.

## Role

The deterministic modules (Risk, Macro & Currency, Opportunity, Signal) produce
numbers, tags, and flags. This layer composes them into a short analyst
narrative — the "personal analyst voice" the owner wants — while staying inside
hard guardrails.

If the layer is disabled or fails, the pipeline emits a **deterministic
rule-based summary** instead and still ships the email (fail-safe). The LLM is
an enhancement, never a dependency.

## Access & model

- **Gemini API** with a free-tier model (e.g. a Flash model), authenticated by
  `GEMINI_API_KEY` (GitHub Secret). This is the **API key**, not the owner's
  Gemini Plus subscription — the two are separate products (see
  `docs/00-overview/02. Architecture.md`).
- One call per weekly run; well within free-tier limits.

## Privacy contract (hard requirement)

The LLM receives a **de-identified payload only**:

- Holdings are referenced as generic labels + attributes, never tickers tied to
  amounts: `"Position A: semiconductor ETF, 53% of portfolio, −2.2% this week"`.
- **No IDR/USD amounts, no account names, no Sheet IDs, no PII.**
- Macro values (yields, VIX, FX **percentage** changes) and dated news
  headlines may be passed, as they are public and non-identifying.

A **pre-send scrubber** validates the payload against a deny-list (currency
symbols with digits, known account strings, the Sheet ID) and **blocks the call
if any real amount is detected**, falling back to the deterministic summary.
This is itself unit-tested (see Test cases).

## Prompt contract

The system prompt pins the analyst role and the guardrails. The model is
instructed to:

1. Explain **what happened and why**, citing the supplied evidence (regime tags,
   flags, dated headlines) — nothing outside the payload.
2. Attach a **limitation** to every claim ("contextual, not causal"; "condition,
   not forecast").
3. **Never** predict prices/returns, never say "buy"/"sell", never invent data
   not in the payload.
4. Keep it concise and structured: *market read → portfolio read →
   concentration & opportunities → risks to watch*.

## Output validation (post-generation guard)

Generated text is validated before it enters the email:

- **Banned-phrase check**: predictive/instructional phrasing ("will crash",
  "going to", "buy now", "sell", price targets) → rejected, fall back to
  deterministic summary.
- **Grounding check**: any number in the narrative must appear in the supplied
  payload (no fabricated figures) → else fall back.
- On any failure the deterministic summary is used and the run is flagged (not
  crashed).

## Output

A `Narrative` result: the validated analyst text plus a `source` field
(`"llm"` or `"deterministic-fallback"`) so the email can label how it was
produced — transparency over illusion.

## Test cases

Tests use a **mocked LLM** (no live API) plus pure-function guards.

1. **TC-01 De-identification.** Given real positions with IDR amounts, the built
   payload contains generic labels and percentages and **zero** real amounts /
   tickers-with-amounts.
2. **TC-02 Scrubber blocks leakage.** A payload containing a real IDR amount is
   detected by the scrubber and the LLM call is **not** made; deterministic
   fallback is used.
3. **TC-03 Banned phrase rejected.** A mocked LLM reply containing "will crash"
   is rejected; `source = "deterministic-fallback"`.
4. **TC-04 Ungrounded number rejected.** A mocked reply citing a figure absent
   from the payload is rejected and falls back.
5. **TC-05 Happy path.** A compliant mocked reply passes both guards and is
   returned with `source = "llm"`.
6. **TC-06 Missing key → fallback.** No `GEMINI_API_KEY` → deterministic summary
   produced, run still succeeds.
7. **TC-07 API error → fallback.** The LLM call raises → deterministic summary,
   run flagged not crashed.
8. **TC-08 Deterministic summary is self-sufficient.** The fallback summary
   contains the market read, portfolio read, concentration, and opportunities
   sections from module outputs alone (no LLM).
