# 04. Signal Engine

## Status

Draft — awaiting review. Upgrade of the predecessor's technical signal logic
(`finance-weekly-report`). Provides the shared technical primitives used by the
Risk and Opportunity modules. Deterministic and auditable; condition labels, not
forecasts.

## Relationship to the predecessor

The predecessor computes SMA50/SMA200, RSI-14, and 52-week drawdown, then maps
them to BUY / HOLD / CAUTION with dynamic advice text. That logic is sound and
is **carried over**. This spec (a) centralizes those primitives so Risk and
Opportunity reuse them instead of duplicating, and (b) adds the evidence +
limitation contract uniformly.

## Primitives (pure functions over a close-price series)

| Function | Definition | Notes |
|----------|------------|-------|
| `sma(closes, n)` | simple moving average of last `n` | `None` if `len < n` |
| `rsi(closes, period=14)` | Wilder's RSI | `None` if `len < period+1`; 100 if no losses |
| `drawdown_from_high(closes, lookback=252)` | % below rolling max | negative = below peak |
| `volatility(closes)` | annualized stdev of daily returns ×√252 | shared with Risk module |
| `change_pct(closes, periods)` | % change over N trading days | 1d, 1w(=5), 1m(=21) |

All primitives are side-effect free and individually unit-tested so Risk,
Opportunity, and the signal label all build on the same verified math.

## Signal decision (per instrument)

Carried over from the predecessor, stated explicitly as a priority ladder.
Inputs: latest price, SMA50, SMA200, RSI, drawdown.

1. **Insufficient history** (SMA200 or RSI unavailable, e.g. newly listed like
   SKHY) → `NEUTRAL / LIMITED DATA`; fall back to 1w change for a soft read.
   Never treat missing SMA200 as a broken trend. *(Preserves the predecessor's
   correct handling of recently listed names.)*
2. **Broken trend** (price < SMA200) → `CAUTION`, regardless of momentum.
3. **Uptrend** (price > SMA200, and > SMA50 when available):
   - RSI ≥ 70 → `HOLD / THIN DCA` (overbought; don't chase).
   - RSI ≤ 30 → `BUY (OVERSOLD)` (intact trend + oversold).
   - RSI 31–69 → `BUY (HEALTHY MOMENTUM)`; discount bonus if drawdown ≤ −10%.
4. **Consolidation** (above SMA200 but below SMA50) → `NEUTRAL / DCA`.

Each signal returns `{label, evidence, limitation}`:
- `evidence`: the measured numbers behind the label (e.g. "price > SMA200,
  RSI 54").
- `limitation`: what the label does **not** claim (e.g. "trend/momentum read of
  current conditions, not a price forecast").

## Guardrails

- No price prediction. Labels are conditions.
- The word "signal" means *condition classification*, never a trade instruction.
- Advice text is dynamic but bounded to the ladder above; no free-form claims.

## Test cases

Deterministic tests over fixed close series.

1. **TC-01 SMA.** `sma([1,2,3,4], 2) = 3.5`; `sma([1,2], 3) = None`.
2. **TC-02 RSI bounds.** Monotonically rising series → RSI near 100; strictly
   falling → near 0; `len < 15` → `None`.
3. **TC-03 Drawdown.** `[100,120,60,90]` → `-50%` from the 120 peak.
4. **TC-04 Volatility.** Constant series → `0`; known synthetic series → matches
   hand-computed value (±1e-6).
5. **TC-05 Change pct.** 1w change equals `close[-1]/close[-6]-1` when ≥ 6
   points.
6. **TC-06 Broken trend wins.** price < SMA200 with RSI 25 → `CAUTION` (not a
   buy), per priority ladder.
7. **TC-07 Overbought uptrend.** price > SMA200 & SMA50, RSI 72 →
   `HOLD / THIN DCA`.
8. **TC-08 Healthy momentum + discount.** uptrend, RSI 55, drawdown −12% →
   `BUY (HEALTHY MOMENTUM)` with discount bonus noted in evidence.
9. **TC-09 Insufficient history.** SMA200 `None` (new listing) → `NEUTRAL /
   LIMITED DATA`, never `CAUTION`.
10. **TC-10 Evidence + limitation present.** Every signal returns non-empty
    `evidence` and `limitation` fields.
